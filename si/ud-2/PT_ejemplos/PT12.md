# 1. Crea los siguientes grupos: 

- **comercial**
- **guía**

#### Comandos:
```bash
sudo groupadd comercial
sudo groupadd guia
```
### Explicacion:
| Comando             | Descripción                            |
| ------------------- | -------------------------------------- |
| `sudo`              | Ejecuta el comando como administrador. |
| `groupadd`          | Crea un nuevo grupo en el sistema.     |
| `comercial`, `guia` | Nombres de los grupos creados.         |

# 2. Crea los siguientes usuarios:

- **guíaPringao**: Su grupo principal es *guía*.Tendrá un directorio personal `/home/guía`. La shell por defecto será *bash* y su contraseña *1234*.  
- **comercialJefe**: Su grupo principal es *comercial* y su grupo secundario es *guía*. Tendrá un directorio personal `/home/comercialJefe`. La shell por defecto sera *bash* y su contraseña *1234*.   
- **comercial1**: Su grupo principal es *comercial*. Tendrá un directorio personal `/home/comercial1`. La shell por defecto sera *bash*  y su contraseña 1234. 

## 🧭 Usuario guiaPringao
```bash
sudo useradd -m -d /home/guia -s /bin/bash -g guia guiaPringao
echo "guiaPringao:1234" | sudo chpasswd
```

### Explicacion:
| Opción          | Significado                                    |
| --------------- | ---------------------------------------------- |
| `-m`            | Crea el directorio personal si no existe.      |
| `-d /home/guia` | Especifica el directorio personal del usuario. |
| `-s /bin/bash`  | Define la shell predeterminada.                |
| `-g guia`       | Grupo principal del usuario.                   |
| `guiaPringao`   | Nombre del usuario.                            |
| `chpasswd`      | comando de Linux que permite a los administradores cambiar las contraseñas. |
**📘 Resultado: Crea el usuario guiaPringao con grupo guia, directorio /home/guia, shell bash y contraseña 1234.**

## 🧭 Usuario comercialJefe
```bash
sudo useradd -m -d /home/comercialJefe -s /bin/bash -g comercial -G guia comercialJefe
echo "comercialJefe:1234" | sudo chpasswd
```
### Explicacion:
| Opción    | Significado                       |
| --------- | --------------------------------- |
| `-G guia` | Añade el grupo secundario `guia`. |
**📘 Resultado: Usuario comercialJefe pertenece a los grupos comercial (principal) y guia (secundario).**

## 🧭 Usuario comercial1
```bash
sudo useradd -m -d /home/comercial1 -s /bin/bash -g comercial comercial1
echo "comercial1:1234" | sudo chpasswd
```

**📘 Resultado: Usuario comercial1 pertenece al grupo comercial, con su directorio /home/comercial1 y shell bash.**

### 3. Dentro del directorio `/opt` crea la siguiente estructura de directorios:  

```bash
/opt$: ls -ltr  
drwxrwxrwx 5 comercialJefe comercial 4096 feb 21 12:40 AgenciaBonVoyage

/opt$: cd AgenciaBonVoyage
/opt/AgenciaBonVoyages$: ls -ltr  

drwxrwxr-- 2 comercialJefe guía      4096 feb 21 12:39 viajes
drwxrwxr-x 2 comercialJefe comercial 4096 feb 21 12:39 guías
drwxr-x--- 2 comercialJefe comercial 4096 feb 21 12:40 Gestion
```

#### Comandos:
```bash
sudo mkdir -p /opt/AgenciaBonVoyage
sudo chown comercialJefe:comercial /opt/AgenciaBonVoyage
sudo chmod 777 /opt/AgenciaBonVoyage
```
## Explicacion:
| Comando     | Descripción                                                |
| ----------- | ---------------------------------------------------------- |
| `mkdir -p`  | Crea la ruta completa, incluyendo directorios intermedios. |
| `chown`     | Cambia propietario y grupo de un archivo o directorio.     |
| `chmod 777` | Da permisos totales a todos (rwxrwxrwx).                   |
**📘 Resultado: Se crean los directorios viajes, guias y Gestion dentro de /opt/AgenciaBonVoyage.**
### 4. Preguntas:

1. ¿Puede el usuario *comercialJefe* escribir en el directorio *viajes*? ¿Por qué? 

```
Sí, puede escribir en el directorio "viajes" porque es el propietario del directorio y los permisos son 774, lo que le da permisos de lectura, escritura y ejecución (rwx) al propietario.
```

2. El "comercial1" tiene que entrar en el directorio "viajes" para consultar los viajes disponibles. ¿Cómo modificarías el directorio "viajes" para que los "guías" puedan seguir accediendo con todos los permisos? 

```
Daría permisos de ejecución al grupo "comercial" (al que pertenece "comercial1") usando:
sudo chmod 775 /opt/AgenciaBonVoyage/viajes

Así, los "guías" (grupo guía) mantienen todos los permisos y el grupo "comercial" podrá acceder y leer el contenido.
```

3. ¿Puede el usuario *guíaPringao* subir su ficha personal (*ficha_personal.doc*) al directorio *guías*?

```
No, no puede. El directorio "guías" pertenece al grupo "comercial" y tiene permisos 775. 
El usuario "guiaPringao" pertenece al grupo "guia", por lo que solo tiene permisos de "otros" (r-x), es decir, puede leer y entrar, pero no escribir.
```
